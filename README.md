# Java Chat Application 💬

A simple chat application built with Java and a graphical user interface (GUI), allowing users to exchange messages through an interactive chat window.

## Features
- User-friendly chat interface
- Send and display messages
- Message history within the session
- Interactive text input and send button

## Technologies
- Java
- Swing / AWT
